_supports Minecraft 26.3.x_

Requirements:
- Fabric Loader: `>=0.19.5`
- Fabric API: `>=0.162.0+26.3`

Changes:
- Made the configuration screen crash-proof when saving: the configuration no longer exposes internal constants to Cloth Config.
- Updated Fabric API, Cloth Config API, and Mod Menu.
